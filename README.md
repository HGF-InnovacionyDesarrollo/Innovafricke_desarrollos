# Innovafricke_desarrollos — Formulario de Registro de Enfermería

Proyecto simple que contiene un formulario de Registro de Enfermería para Hospitalización Domiciliaria.

Qué incluye:
- `index.html`: formulario responsive optimizado para tablet con campos de identificación, signos vitales, procedimientos y plan de enfermería.
- `.gitignore`

Campo añadido recientemente:
- **Sat. O₂**: valor de saturación en %.
- **Fuente de O₂**: selector asociado para indicar si la medición fue en `Ambiental (aire ambiente)` o `Con oxígeno suplementario`.

Vista pública (GitHub Pages):
https://hgf-innovacionydesarrollo.github.io/Innovafricke_desarrollos/

Cómo usar:
1. Abrir `index.html` en el navegador (o usar la URL pública).
2. Completar los campos del formulario y usar los botones para guardar o finalizar (actualmente el formulario es estático y no persiste en servidor).

Si quieres que el formulario guarde datos (localStorage o backend), puedo implementarlo en el siguiente paso.
